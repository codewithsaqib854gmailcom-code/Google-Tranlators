# Global Text & Document Translator

Welcome to Global Text & Document Translator!

A free and easy-to-use online platform designed to help users translate text and documents into different languages.

## Features
- Word Translation
- Sentence Translation
- Paragraph Translation
- Document Translation
- Multiple Language Support
- Simple and User-Friendly Interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Website Purpose
Our goal is to make language translation simple and accessible for everyone around the world.
